# EBB 1.3.0: the art redesign

> This release was first published as "EBB-release" under the tag `1.0.0`. The installer in it
> has always been EBB 1.3.0 (the game's title screen and the exe's properties say so); the tag
> keeps its old name so that existing links still work. For the newest version, see the latest
> release.

Every sprite, tile, effect, font and sound in EBB redrawn over twenty-three stages, to one style
bible (`STYLE.md`): a palette of night and salt, 16 px tiles at 640x360, and lights that the
lantern outshines. A new icon, and the game delivered as one setup file.

**Download `EBB-Setup-1.3.0.exe` below and run it.** It installs for your user with no admin
rights, puts shortcuts on the Desktop and Start menu, and appears in Apps & features. Saves live
outside the install and survive updates and uninstalls.
